# CareFlow Dashboard Wireframe

## Page 1: Executive Summary
- Total patient cases
- Total recorded events
- Average case duration
- Loop-back rate
- Before vs After comparison

## Page 2: Process Map
- Patient activity flow
- Activity frequency
- Process transitions
- Department and age-group filters

## Page 3: Bottlenecks
- Average transition time
- Longest waiting transitions
- X-Ray to Triage loop-back rate
- Loop-back reasons

## Page 4: Conformance
- Compliant cases
- Non-compliant cases
- Conformance percentage
- Deviations from the ideal journey

## Data Source
Processed event-log tables supplied by the team.
