# CareFlow Dashboard Wireframe

## BI Tool Selection
- Primary BI Tool: Power BI
- Fallback BI Tool: Looker Studio

## Page 1: Overview
- Total patient cases
- Total recorded events
- Average case duration
- Loop-back rate
- Before vs After comparison
- Filters: Department and Age Group

## Page 2: Process Map
- Patient activity flow
- Activity frequency
- Process transitions
- Department filter
- Age-group filter

## Page 3: Bottlenecks
- Average transition time
- Longest waiting transitions
- X-Ray to Triage loop-back rate
- Loop-back reasons
- Identify transitions with long waiting times

## Page 4: Conformance
- Compliant cases
- Non-compliant cases
- Conformance percentage
- Deviations from the ideal clinical pathway

## Data Source
Processed event-log tables supplied by the team.

## Notes
- Dashboard metrics will be calculated using validated project data.
- Final values will be added after the required data is available.
- The wireframe describes the planned dashboard layout, not final results.
